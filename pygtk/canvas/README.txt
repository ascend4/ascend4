
Canvas-based modelling for ASCEND

For full details and screenshots see 
http://ascendwiki.cheme.cmu.edu/Canvas-based_modeller_for_ASCEND

This version is being ported to Python 3, PyGObject/Gtk3 and the
Gtk3-compatible Gaphas 3 API. Later Gaphas 5 releases have moved further
toward Gtk4-style event controllers, so a Gtk3 build should pin Gaphas to the
3.x line until the rest of the canvas interaction tools are ported.
