## Name Registry Inputs

This directory separates:

- generated alias candidates from source databases
- manual override aliases curated by developers
- generated merged C registry output

Files:

- [canonicals.yml](/home/john/ascend/models/johnpye/fprops/names/canonicals.yml)
  Manual canonical-name additions for thermo namespaces that are not yet
  covered by autogenerated source-data candidates.
- [aliases.yml](/home/john/ascend/models/johnpye/fprops/names/aliases.yml)
  Manual overrides and curated aliases. This file should not be
  overwritten by generators. It should only point at canonicals that
  already exist in the auto-generated or curated canonical source-data.
- `generated/rpp_name_candidates.yml`
  Auto-generated from `convcomp.py`.
- `generated/unifac_name_candidates.yml`
  Auto-generated from `mixtures/convunifac.py`.
- `convnames.py`
  Merge step that combines auto-generated candidates and manual
  overrides into a generated C registry.
- `_name_registry.c`
  Generated output from `convnames.py`.

Typical workflow:

```bash
python3 models/johnpye/fprops/convcomp.py \
  --emit-name-candidates models/johnpye/fprops/names/generated/rpp_name_candidates.yml
```

```bash
python3 models/johnpye/fprops/mixtures/convunifac.py \
  --emit-name-candidates models/johnpye/fprops/names/generated/unifac_name_candidates.yml
```

```bash
python3 models/johnpye/fprops/names/convnames.py \
  --emit-c models/johnpye/fprops/names/_name_registry.c
```
